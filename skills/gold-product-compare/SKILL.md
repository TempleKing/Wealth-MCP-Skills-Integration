# 黄金产品对比 Skill

## 1. 功能范围

本 Skill 用于黄金产品的客观价格对比，第一版主要覆盖：

* 各银行积存金报价对比；
* 伦敦金价格参考；
* 汇率换算后的黄金价格参考；
* 不同报价之间的相对高低；
* 数据日期和报价来源说明；
* 价格比较的风险和限制。

本 Skill 不负责黄金行情原因分析、黄金概念解释、黄金资产配置、个性化推荐或交易执行。

---

## 2. When to Use

当用户提出以下问题时，使用本 Skill：

* 哪家银行积存金价格更低？
* 今天各银行积存金报价是多少？
* 帮我比较一下不同银行的积存金价格。
* 现在积存金哪个渠道报价相对便宜？
* 银行积存金价格和伦敦金参考价有什么差异？
* 各银行黄金报价差距大吗？

用户只问黄金价格时，也可以使用本 Skill 简洁展示报价。

---

## 3. When NOT to Use

以下问题不要用本 Skill 直接完成：

1. 黄金为什么上涨或下跌。
2. 黄金后续走势怎么看。
3. 积存金是什么、黄金 ETF 是什么等概念解释。
4. 积存金、金条、黄金 ETF 的产品机制科普。
5. 根据用户情况推荐买哪种黄金产品。
6. 判断现在是否应该买黄金。
7. 执行黄金买入、卖出或定投。
8. 查询用户持仓、风险偏好或个人资产情况。
9. 比较手续费、点差、赎回、交易时间、起购门槛等当前工具未稳定返回的字段。

概念解释类问题应转向 `financial-concept-faq-explainer`。黄金行情分析类问题应转向市场或财富研究分析 Skill。

## 6. 返回结果解析规则

财富 MCP Tools 通常返回统一外层结构：

```json id="iy84tr"
{
  "code": "...",
  "success": true,
  "message": "...",
  "class": "...",
  "data": "..."
}
```

处理规则：

1. 先检查 `success` 和 `code`。
2. `data` 为字符串时，应二次解析。
3. 优先提取银行名称、积存金价格、伦敦金价格、汇率换算价格和数据日期。
4. 只展示与用户问题相关的字段。
5. 字段缺失时明确标注，不得自行补充。
6. 不展示完整原始 JSON、内部 class、debug 信息或接口路径。
7. 价格比较必须标注数据时间。
8. 不把价格低直接等同于总成本低。

## 7. 工作流策略：四步黄金产品价格对比法

### Step 1：识别比较目标

识别用户关注的是：

* 最新报价；
* 指定日期报价；
* 银行之间价格高低；
* 银行报价与伦敦金参考价差异；
* 近期规则或公告变化。

如果用户问的是黄金产品概念或机制，应转向概念解释 Skill。

---

### Step 2：获取黄金报价

调用 `queryGoldPrice_7224`，获取：

* 各银行积存金报价；
* 伦敦金价格；
* 汇率换算参考价；
* 数据日期。

如果用户指定日期，使用对应 `queryDate`。

---

### Step 3：比较价格差异

在工具返回范围内比较：

* 哪家银行报价相对较低；
* 哪家银行报价相对较高；
* 最高价与最低价差异；
* 银行报价与参考价格的差异；
* 数据时间是否一致。

处理规则：

1. 只比较同一时间口径下的价格。
2. 报价最低不等于总成本最低。
3. 不自行计算工具未返回的手续费、点差或赎回成本。
4. 不根据单次报价判断长期优劣。
5. 不输出“最划算”这类确定性结论，除非完整成本字段可验证。

---

### Step 4：输出结论和边界

输出应包括：

1. 数据日期；
2. 各银行报价；
3. 相对低价和高价；
4. 报价差异；
5. 当前无法覆盖的成本字段；
6. 风险提示。

推荐表达：

* 从当前工具返回的报价看，A 银行积存金价格相对较低。
* 但完整购买成本还需要结合手续费、买卖价差、赎回规则和交易时间判断。
* 当前工具未返回这些规则字段，因此不能直接判断哪家总成本最低。
* 以上为价格对比，不构成黄金产品推荐或交易建议。

## 10. 错误与降级处理

### 黄金价格查询失败

1. 说明当前未成功获取黄金报价。
2. 不自行生成银行报价。
3. 可提示用户稍后重试或指定日期。

### 部分银行报价缺失

1. 展示已返回的银行报价。
2. 标注缺失银行或缺失字段。
3. 不使用历史报价补充当前报价。

### 数据日期不一致

1. 不直接比较价格高低。
2. 说明报价时间口径不一致。
3. 仅做分开展示。

### 用户要求推荐

说明：

> 当前 Skill 只支持公开报价对比，不读取用户画像，也不提供个性化黄金产品推荐。

### 用户要求比较手续费或赎回规则

如果工具未返回相关字段，应说明：

> 当前工具未返回手续费、点差、赎回、交易时间和起购门槛，因此无法完成完整成本比较。
