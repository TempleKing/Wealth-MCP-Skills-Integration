# 财经资讯摘要 Skill

## 1. 功能范围

本 Skill 用于处理财富管理场景下的财经资讯摘要，包括：

* 市场新闻：A 股、港股、美股、指数和市场情绪相关资讯；
* 宏观政策：政策、利率、汇率、通胀、监管等事件；
* 行业板块：重要行业、主题和赛道热点；
* 基金理财：基金发行、基金经理、产品事件和理财市场资讯；
* 黄金商品：金价、积存金、美元、利率和避险情绪相关信息；
* 个股事件：重点公司新闻、公告和行业事件背景。

本 Skill 只负责“发生了什么、影响哪些方向、后续关注什么”，不输出买卖建议、目标价或个性化投资判断。

---

## 2. When to Use

当用户提出以下问题时，使用本 Skill：

* 今天市场有什么重要新闻？
* 总结今天的财经热点。
* 今天 A 股有什么大事？
* 最近市场关注哪些主线？
* 今天基金圈有什么新闻？
* 黄金最近有什么重要消息？
* 今天有哪些股票或行业热点？
* 帮我按市场、黄金、股票整理一下财经新闻。

用户未指定范围时，默认覆盖：

1. 市场整体；
2. 宏观与政策；
3. 行业与板块；
4. 基金与理财；
5. 黄金与大宗；
6. 重点公司事件。

---

## 3. When NOT to Use

以下问题不要用本 Skill 直接完成：

1. 深度分析某个市场、板块、基金或股票。
2. 判断某只基金或股票是否值得买。
3. 查询用户持仓受哪些新闻影响。
4. 输出个性化资产配置建议。
5. 执行买入、卖出、加仓或减仓。
6. 预测明天市场涨跌。
7. 给出目标价、收益承诺或明确交易结论。

如用户问题转向具体资产深度分析，应转向对应分析 Skill。

## 4. 场景识别与工具路由

| 用户意图 | 优先 Tool | 用途 |
| ---------- | -------------------------- | ----------------- |
| 财经热点、新闻摘要 | `search_3347` | 检索资讯标题、正文、来源和时间 |
| 今日市场整体状态 | `queryMarketOverview_7193` | 获取涨跌家数、强弱赛道等市场概览 |
| 指数、市场和资产行情 | `queryMarketData_3101` | 补充市场行情事实 |
| 市场方向性研判 | `queryMarketAnalysis_3106` | 补充市场分析观点 |
| 黄金相关热点 | `queryGoldPrice_7224` | 补充黄金和积存金价格事实 |
| 具体股票新闻背景 | `queryStockKypInfo_7192` | 补充股票基础画像，不做深度估值分析 |

工具调用原则：

1. `search_3347` 是资讯摘要核心工具。
2. 市场类问题可调用 `queryMarketOverview_7193` 或 `queryMarketData_3101` 补充事实。
3. 黄金新闻可调用 `queryGoldPrice_7224` 补充价格背景。
4. 涉及具体股票时，`queryStockKypInfo_7192` 只补充公司画像。
5. 不把新闻和行情直接包装成唯一因果关系。
6. 不默认输出深度投研分析。

## 5. 参数构造规则

### 5.1 资讯检索：`search_3347`

从用户问题中提取时间、市场、资产类别和主题。

示例：

```json
{
  "query": "今日财经热点 A股 基金 黄金 股票 重要新闻",
  "maxSize": 10
}
```

用户指定黄金：

```json
{
  "query": "今日黄金市场重要新闻 金价 美元 利率 避险情绪",
  "maxSize": 5
}
```

用户指定股票：

```json
{
  "query": "宁德时代近期重要新闻 公司事件 行业影响",
  "maxSize": 5
}
```

处理规则：

1. 保留用户指定时间范围。
2. 优先选择与财富业务相关的资讯。
3. 去除重复新闻。
4. 保留来源和发布时间。
5. 资讯不足时明确说明。

---

### 5.2 市场概览和行情补充

市场整体问题可调用：

* `queryMarketOverview_7193`：补充涨跌家数、强弱赛道；
* `queryMarketData_3101`：补充指数、市场或资产行情；
* `queryMarketAnalysis_3106`：补充市场分析观点。

示例：

```json
{
  "query": "今日A股市场行情"
}
```

---

### 5.3 黄金价格补充

黄金相关问题调用 `queryGoldPrice_7224`。

规则：

* 不传 `queryDate`：查询实时或最新金价；
* 用户指定历史日期时，传入 `queryDate`。

## 6. 返回结果解析规则

财富 MCP Tools 通常返回统一外层结构：

```json
{
  "code": "...",
  "success": true,
  "message": "...",
  "class": "...",
  "data": "..."
}
```

处理规则：

1. 先检查 `success` 和 `code`。
2. `data` 为字符串时，应二次解析为 JSON。
3. 资讯类结果优先提取标题、摘要、来源、发布时间。
4. 行情类结果必须标注数据时间。
5. 不展示完整原始 JSON、内部 class、debug 信息。
6. 字段缺失时明确说明，不自行补充。
7. 不将单条资讯观点表述为市场共识。
8. 不将市场涨跌直接归因于某一条新闻。

## 7. 工作流策略：五步财经资讯摘要法

### Step 1：识别摘要范围

识别用户需要摘要的范围：

* 全市场；
* A 股、港股、美股；
* 基金或理财；
* 黄金或商品；
* 股票或具体公司；
* 行业、板块或主题；
* 今日、本周、最近等时间范围。

用户未指定时间时，默认理解为“近期或当日”。

---

### Step 2：检索资讯

调用 `search_3347` 获取相关资讯。

筛选原则：

1. 优先保留近期资讯。
2. 优先保留与市场、基金、黄金、股票相关的信息。
3. 合并重复事件。
4. 删除明显无关内容。
5. 每个主题保留 1～3 条核心信息。

资讯摘要应回答：

* 发生了什么；
* 涉及哪些市场或资产；
* 可能影响什么方向；
* 后续需要关注什么。

---

### Step 3：补充市场或资产事实

根据用户问题选择事实补充：

* 市场整体：`queryMarketOverview_7193`
* 市场行情：`queryMarketData_3101`
* 市场研判：`queryMarketAnalysis_3106`
* 黄金价格：`queryGoldPrice_7224`
* 个股画像：`queryStockKypInfo_7192`

事实补充用于帮助用户理解新闻背景，不替代新闻摘要本身。

不得把“市场当天涨跌”和“某条新闻”直接绑定为确定因果。

---

### Step 4：分类整理摘要

推荐按以下类别输出：

1. 市场走势；
2. 宏观与政策；
3. 行业与板块；
4. 基金与理财；
5. 黄金与大宗；
6. 重点公司事件；
7. 后续关注。

每条摘要尽量控制在三句话以内：

* 新闻事实；
* 可能影响；
* 关注点。

---

### Step 5：输出边界和风险提示

结尾说明：

* 资讯摘要不构成投资建议；
* 新闻影响需要后续市场验证；
* 单条新闻不能解释全部市场波动；
* 数据和资讯可能存在延迟；
* 不建议仅根据新闻进行交易决策。

不得输出买入、卖出、加仓、减仓或目标价。

---

## 8. 大量资讯处理规则

当 `search_3347` 返回多条资讯时：

1. 优先按主题聚类，而不是逐条罗列；
2. 同一事件多条资讯只保留最清晰的一条；
3. 来源不同但内容相同的资讯合并摘要；
4. 信息冲突时不强行合并，应说明存在不同说法；
5. 没有发布时间的资讯不作为“今日新闻”核心依据；
6. 不展示过长正文。

推荐摘要格式：

```text
【主题】一句话标题
- 发生了什么：
- 可能影响：
- 后续关注：
```

---

## 9. 输出规范

### 推荐输出结构

```text
一、今日市场概览
- 市场整体表现：
- 强弱方向：

二、重要财经热点
1. 宏观与政策：
2. 行业与板块：
3. 基金与理财：
4. 黄金与大宗：
5. 重点公司事件：

三、可能影响
- 对市场情绪：
- 对相关资产：
- 对后续观察：

四、风险提示
- 以上为资讯摘要，不构成投资建议。
```

总体要求：

1. 先给总览，再分主题摘要。
2. 每条新闻标注来源和时间，若工具返回。
3. 保持中性，不夸大影响。
4. 不编造未返回的新闻、数据或结论。
5. 不把资讯摘要扩展成买卖建议。
6. 不输出“必涨”“利好兑现”“赶紧上车”等表达。
7. 用户只问简短摘要时，控制篇幅。

## 11. 错误与降级处理

### 资讯检索失败

1. 说明当前未成功获取资讯。
2. 可使用市场概览或行情工具提供基础市场事实。
3. 不自行生成新闻。

### 市场概览失败

可以继续基于资讯摘要输出，但不得补充市场涨跌家数或强弱赛道。

### 黄金价格失败

可以继续摘要黄金相关新闻，但不得补充实时金价。

### 资讯时间不明确

不表述为“今日最新”，应改为“近期资讯显示”。

### 用户要求投资建议

应说明本 Skill 只做资讯摘要，不提供个性化投资建议或交易决策。

## 12. 示例流程

### 示例 1：全市场财经摘要

用户：

> 今天市场有什么重要新闻？

流程：

1. 调用 `search_3347` 检索今日财经热点。
2. 调用 `queryMarketOverview_7193` 补充市场概览。
3. 必要时调用 `queryMarketData_3101` 补充行情事实。
4. 按市场、宏观、行业、基金、黄金、公司事件分类摘要。
5. 输出后续关注和风险提示。

---

### 示例 2：黄金新闻摘要

用户：

> 今天黄金有什么重要消息？

流程：

1. 调用 `search_3347` 检索黄金相关新闻。
2. 调用 `queryGoldPrice_7224` 补充金价事实。
3. 摘要美元、利率、避险情绪和黄金价格相关信息。
4. 提示金价受多因素影响，不构成投资建议。

---

### 示例 3：股票事件摘要

用户：

> 最近宁德时代有什么新闻？

流程：

1. 调用 `search_3347` 检索公司近期资讯。
2. 必要时调用 `queryStockKypInfo_7192` 补充公司行业和主营业务。
3. 按公司事件、行业背景和可能影响输出。
4. 不判断股票是否应该买卖。

---

### 示例 4：市场热点摘要

用户：

> 总结今天的财经热点，简单一点。

流程：

1. 调用 `search_3347`。
2. 必要时调用 `queryMarketOverview_7193`。
3. 输出 3～5 条最重要热点。
4. 每条控制在一句到两句。
