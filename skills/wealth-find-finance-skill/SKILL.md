# 财富管理能力发现与路由

把用户问题路由到最匹配的财富场景 Skill，并确认财富 MCP 已连接。本 Skill 不直接编造或替代金融数据。

## 执行流程

1. 读取 [skills-catalog.md](references/skills-catalog.md)，按用户目标选择一个主要 Skill；只有确有必要时再选择一个补充 Skill。
2. 检查目标 Skill 是否已安装。不要因为历史对话或文件名曾出现就假定已安装。
3. 检查是否能看到财富 MCP 工具。优先检查 `queryKypInfo_3107`、`queryMarketData_3101`、`querySecuQuote_7681` 或 `queryGoldPrice_7224`。
4. Skill 和 MCP 均可用时，将任务交给目标 Skill，保留用户原始问题和约束。
5. 缺少 Skill 时，说明缺少的名称和用途；获得用户确认后，使用当前平台的原生 Skill 安装机制从本 Skill 的来源仓库安装。
6. 缺少 MCP 时，读取 [mcp-setup.md](references/mcp-setup.md)。修改平台配置前必须向用户说明目标位置和连接地址并取得确认。

## 路由原则

- 单项数据查询优先使用 `financial-indicator-query`。
- 单基金研究、基金对比和基金候选发现使用各自专用 Skill，不互相替代。
- 市场行情解释与财经资讯摘要分开处理；前者关注市场现象，后者关注事件和来源。
- 股票研究与多股票对比分开处理。
- 概念解释不调用个性化工具；可以由 FAQ 工具补充权威口径。
- 涉及 KYC、用户记忆、个人指标、资产配置或持仓陪伴时，先确认权限和用户授权。
- MCP 返回为空或失败时报告真实状态，不用模型记忆补充实时数据。

## 安装边界

- 当前版本只支持原生远程 MCP，不包含 Node/Python CLI 桥接层。
- 平台不支持自定义 MCP 且无法安装 Plugin 时，明确报告不支持，不要声称安装成功。
- 不默认启用 `autoApprove`。工具审批由目标平台和用户决定。
- 当前 Gateway 是内网 HTTP SSE 地址；不可访问时停止并说明网络限制。

## 完成条件

仅在以下条件满足时继续业务任务：

1. 目标场景 Skill 可发现；
2. 至少一个所需财富 MCP Tool 可发现；
3. 用户问题中的对象、时间范围和输出目标足够明确。
