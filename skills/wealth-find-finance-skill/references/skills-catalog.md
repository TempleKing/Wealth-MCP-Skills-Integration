# 财富 Skill 目录

| Skill | 适用问题 |
| --- | --- |
| `financial-indicator-query` | 查询基金、股票、指数、黄金或市场的单项或少量指标 |
| `fund-comprehensive-eval` | 对一只基金进行收益、风险、回撤、持仓和经理等综合评测 |
| `fund-compare-analysis` | 横向比较 2～5 只明确基金 |
| `fund-candidate-discovery` | 按主题、类型、风格或历史指标寻找基金候选 |
| `market-quote-diagnosis` | 解读市场或板块的盘中、盘后涨跌现象 |
| `financial-news-briefing` | 汇总市场、基金、股票或黄金的重要财经资讯 |
| `stock-comprehensive-research` | 对一只股票进行公司、行业、行情和事件的轻量研究 |
| `stock-compare-analysis` | 横向比较 2～5 只明确股票 |
| `gold-product-compare` | 比较银行积存金、伦敦金参考价和汇率换算价格 |
| `cross-asset-relation-navigation` | 查询板块、基金、股票之间的持仓和行业关系 |
| `financial-concept-faq-explainer` | 解释金融概念、指标、产品规则和业务口径 |

## 选择规则

1. 优先选择与用户最终交付物最接近的一个 Skill。
2. 查数据只是分析的一个步骤时，以分析 Skill 为主，`financial-indicator-query` 不单独作为第二流程。
3. 用户同时提出两个独立目标时，才组合两个 Skill，并说明执行顺序。
4. 用户要求买卖、交易执行或收益承诺时，不路由为可执行交易任务；只提供客观数据、分析框架和风险说明。
