# 金融概念解释 Skill

## 1. 功能范围

本 Skill 用于解释财富管理场景中的金融概念、指标和基础产品知识，包括：

* 收益指标：收益率、年化收益率、累计收益、超额收益等。
* 风险指标：最大回撤、波动率、夏普率、风险等级等。
* 基金知识：基金净值、基金份额、A 类与 C 类、申购赎回等。
* 股票与市场：市盈率、市净率、指数、板块、成交量等。
* 黄金知识：积存金、伦敦金、黄金定价和影响因素等。
* 资产配置：股票、债券、商品、现金等基础概念。
* 金融政策或市场新概念的背景解释。

本 Skill 负责回答“概念是什么、怎么看、有什么用、有什么区别”，不负责判断某只具体资产当前是否值得投资。

---

## 2. When to Use

当用户提出以下问题时，使用本 Skill：

### 标准概念

* 最大回撤是什么？
* 什么是基金净值？
* 夏普率代表什么？
* 市盈率是什么意思？
* 什么是指数增强基金？

### 指标理解

* 夏普率越高越好吗？
* 最大回撤应该怎么看？
* 波动率高说明什么？
* 基金规模大好还是小好？

### 概念对比

* 最大回撤和波动率有什么区别？
* A 类基金和 C 类基金有什么区别？
* 主动基金和指数基金有什么区别？
* 场内基金和场外基金有什么区别？

### 产品与业务知识

* 积存金是什么？
* ETF 是什么？
* 基金申购和认购有什么区别？
* 基金分红是什么意思？

### 通俗解释

* 用简单的话解释夏普率。
* 能不能举例说明最大回撤？
* 用小白能懂的话解释复利。
* 为什么收益高不代表基金一定更好？

### 时效性概念

* 最近市场说的某个新政策是什么意思？
* 最近常说的“红利策略”是什么？
* 某项新规则对基金有什么影响？

---

## 3. When NOT to Use

以下问题不要用本 Skill 直接完成：

1. 查询具体基金、股票、指数或黄金的实时行情。
2. 分析某只基金当前收益、回撤或持仓表现。
3. 比较多只基金、股票或其他资产。
4. 判断某个产品是否值得购买。
5. 推荐基金、股票、黄金或资产配置方案。
6. 执行买入、卖出、加仓或减仓。
7. 根据用户个人情况提供个性化投资建议。
8. 预测具体涨跌幅、目标价或未来收益。
9. 查询用户持仓、风险测评或个人资产信息。

例如：

* “夏普率是什么？”属于本 Skill。
* “005827 的夏普率表现怎么样？”应转向基金分析 Skill。
* “积存金是什么？”属于本 Skill。
* “现在积存金多少钱？”应转向黄金行情查询场景。

财富 MCP Tools 通常返回统一外层结构：

```json

  "code": "...",
  "success": true,
  "message": "...",
  "class": "...",
```

处理规则：

1. 先检查 `success` 和 `code`。

7. 工具未返回的信息不得自行补充为确定性事实。
8. 不展示 MCP URL、内部 class、debug 信息或完整原始 JSON。

## 8. 工作流策略：五步金融概念解释法

### Step 1：识别概念与解释目标

识别用户询问的是：

* 金融概念；
* 风险或收益指标；
* 产品类型；
* 交易或业务规则；
* 多个概念的区别；
* 近期政策或市场新概念。

同时识别用户希望获得的解释方式：

* “是什么”：说明标准定义；
* “怎么看”：解释数值或特征代表什么；
* “有什么用”：解释使用场景；
* “有什么区别”：对比相近概念；
* “举个例子”：提供简单假设案例；
* “简单解释”：减少专业术语；
* “专业解释”：补充计算逻辑和局限。

---

### Step 2：获取标准知识

标准金融概念优先调用 `queryFaq_3104`。

从 FAQ 中提取：

* 核心定义；
* 指标含义；
* 产品特征；
* 适用场景；
* 常见注意事项；
* 与相近概念的区别。

如果 FAQ 返回多个结果：

1. 优先选择与用户问题最相关的问答；
2. 合并重复内容；
3. 忽略明显不相关结果；
4. 必要时保留 2～3 个相关问题供用户继续了解。

---

### Step 3：补充通俗理解

当用户要求简单解释、举例或 FAQ 内容过于专业时，可调用 `joyAsk_6375`。

解释应尽量包含：

1. 一句话定义；
2. 通俗理解；
3. 简单例子；
4. 实际用途；
5. 注意事项。

例如解释最大回撤：

* 定义：历史上从阶段高点到后续低点的最大跌幅。
* 通俗理解：可以理解为一项投资历史上最难熬的一段下跌。
* 示例：净值从 1.50 下跌到 1.20，对应回撤为 20%。
* 用途：用于观察历史下跌风险和持有体验。
* 注意：历史最大回撤不代表未来不会出现更大跌幅。

示例数字必须明确属于假设，不得冒充真实产品数据。

---

### Step 4：说明应用方式和限制

解释指标时，不只说明“是什么”，还应说明“怎么用”。

常见规则：

* 收益指标应结合风险指标观察；
* 最大回撤和波动率需要在相近资产类型、相同统计周期下比较；
* 夏普率用于观察历史风险调整后收益，不能单独判断产品未来表现；
* 基金规模、费率和风险等级不能脱离基金类型单独判断好坏；
* 单一指标不足以构成完整投资决策；
* 历史数据不代表未来收益。

如果工具未提供某项公式、规则或产品条款，不得自行编造。

---

### Step 5：给出边界和相关延伸

回答结尾可以补充：

* 该概念与哪些指标容易混淆；
* 还可以关注哪些相关概念；
* 当前解释不适用于哪些场景。

例如：

> 最大回撤主要反映历史上最深的一次下跌，而波动率反映一段时间内价格变化的整体幅度，两者不能相互替代。

必要时根据 FAQ 结果列出相关问题：

* 最大回撤和波动率有什么区别？
* 夏普率越高越好吗？
* 如何同时观察基金收益和风险？

不得在概念解释后直接引导用户购买具体产品。

## 9. 不同问题的解释规则

### 9.1 指标定义类

推荐结构：

```text
一句话解释：
- ……

通俗理解：
- ……

怎么看：
- ……

需要注意：
- ……
```

适用于：

* 最大回撤；
* 波动率；
* 夏普率；
* 市盈率；
* 年化收益率。

---

### 9.2 多概念对比类

优先使用表格比较：

| 对比维度 | 概念 A | 概念 B |
| ---- | ---- | ---- |
| 核心含义 |      |      |
| 主要用途 |      |      |
| 适用场景 |      |      |
| 主要限制 |      |      |

对比应以工具返回的定义为基础，不得为了形成差异而编造不存在的结论。

---

### 9.3 产品知识类

解释产品时优先说明：

* 产品是什么；
* 基本运作方式；
* 收益或价格来源；
* 主要风险；
* 与相近产品的区别。

例如解释积存金时，应区分：

* 产品基础含义；
* 黄金价格波动风险；
* 具体银行规则和费率。

具体银行的起购金额、手续费和交易时间可能变化。工具未返回或用户未指定机构时，不得给出确定性规则。

---

### 9.4 近期政策和市场新概念

使用 `search_3347` 时，应说明：

* 概念出现的背景；
* 相关政策或事件；
* 对市场可能产生的影响；
* 信息来源和发布时间；
* 当前解释可能随政策变化而更新。

不得将单篇资讯观点表述为市场共识或确定性结论。

## 10. 输出规范

### 推荐输出结构

```text
一句话解释：
- ……

通俗理解：
- ……

举个例子：
- 假设……

实际怎么看：
- ……

需要注意：
- ……
```

总体要求：

1. 先回答用户的核心问题，不堆砌无关知识。
2. 默认使用通俗语言，必要时再补充专业定义。
3. 公式不是必需内容，只有帮助理解时才展示。

5. 不编造工具未返回的规则、费率或政策。
6. 不将概念解释转化为具体产品推荐。
7. 不使用“稳赚”“保本”“一定上涨”等确定性表达。
8. 涉及金融产品时，附带简短风险提示。
9. 输出结构可根据问题复杂度调整，不要求每次机械套用完整模板。

## 12. 错误与降级处理

### `queryFaq_3104` 未返回相关结果

1. 可调用 `joyAsk_6375` 尝试通用解释。
2. 明确说明当前 FAQ 知识库未检索到直接答案。
3. 不编造具体产品规则或政策内容。

### `joyAsk_6375` 调用失败

1. 如果 FAQ 已成功返回，基于 FAQ 内容进行简洁解释。
2. 不因缺少生成式补充而中断回答。
3. 不自行添加未经知识库支持的复杂结论。

### 多条 FAQ 内容冲突

1. 不强行合并。
2. 说明知识库返回内容存在口径差异。
3. 优先保留与用户问题最相关、表述最明确的内容。
4. 涉及具体制度时，可使用 `search_3347` 核实近期背景。

### 时效性信息不足

1. 说明当前资讯不足以确认最新规则。
2. 不使用历史规则代替当前规则。
3. 可给出不依赖具体时间的基础概念解释。

### 问题超出范围

如果用户实际询问具体资产表现，应说明：

> 这个问题已经涉及具体资产数据，需要由对应的基金、股票、市场或黄金分析能力处理；本 Skill 只负责解释概念本身。
