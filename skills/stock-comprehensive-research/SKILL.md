# 个股综合分析 Skill

## 1. 功能范围

本 Skill 用于处理具体股票的轻量综合分析，包括：

* 公司画像：交易所、所属申万行业、行业代码、主营业务；
* 行业分析：PEST、SWOT、波特五力和工具返回的基本面总结；
* 行情表现：当前或指定日期的价格、涨跌幅；
* 事件背景：近期公司、行业和政策资讯；
* 综合总结：公司特点、行业机会、主要压力和风险。

本 Skill 不提供完整财务研究、估值判断、技术分析、目标价或个性化买卖建议。

---

## 2. When to Use

当用户提出以下问题时，使用本 Skill：

* 帮我分析一下宁德时代。
* 贵州茅台主要做什么？
* 这家公司属于什么行业？
* 这只股票最近表现怎么样？
* 这家公司有哪些优势和风险？
* 最近为什么上涨或下跌？
* 某项行业政策对这家公司有什么影响？
* 从行业和公司角度怎么看这只股票？

用户未指定分析重点时，默认分析：

1. 公司与业务画像；
2. 所属行业及外部环境；
3. 工具返回的优势、压力与风险；
4. 当前行情；
5. 必要的近期资讯；
6. 当前数据能力边界。

---

## 3. When NOT to Use

以下问题不要用本 Skill 直接完成：

1. 查询或分析 PE、PB、PS、估值分位。
2. 分析营业收入、净利润、现金流、ROE 等财务指标。
3. 分析均线、MACD、支撑位、压力位等技术指标。
4. 查询主力资金、北向资金或其他资金流向。
5. 查询机构评级、目标价或盈利预测。
6. 比较多只股票并进行严格排名。
7. 全市场选股或股票推荐。
8. 要求买入、卖出、加仓或减仓。
9. 要求预测具体涨跌幅或承诺收益。

如果用户询问当前工具不支持的维度，应明确说明数据缺失，不得使用模型常识补全。

## 4. 场景识别与工具路由

| 用户意图 | 优先 Tool | 用途 |
| ------------ | ------------------------ | -------------- |
| 公司画像、行业和综合分析 | `queryStockKypInfo_7192` | 获取基础信息和生成式分析文本 |
| 当前或历史行情 | `querySecuQuote_7681` | 获取价格、涨跌幅和数据日期 |
| 近期公司或行业事件 | `search_3347` | 补充资讯来源、正文和发布时间 |

工具调用原则：

1. 综合个股分析优先调用 `queryStockKypInfo_7192`。
2. 用户询问行情或综合分析需要最新价格时，调用 `querySecuQuote_7681`。
3. 用户询问近期变化、政策或涨跌背景时，调用 `search_3347`。
4. `search_3347` 不替代结构化公司数据。
5. 不因用户问“怎么看”就输出买卖建议。

## 5. 参数构造规则

### 5.1 股票综合画像

股票名称明确时，使用 `skShortNameList`：

```json
{
  "skShortNameList": ["宁德时代"]
}
```

股票代码明确时，使用 `skInnerCodeList`。
```json
{
  "skInnerCodeList": ["000001.SZ", "600519.SH", "300750.SZ"]
}
```

处理规则：

1. 名称模糊匹配结果与用户输入高度一致时，可以继续。
2. 返回对象明显不一致时，应先确认。
3. 无意义名称或查询失败时，停止后续分析。
4. 不得根据模型记忆自行生成股票代码。

---

### 5.2 股票行情

根据名称或代码构造：

```json
{
  "secuNames": ["宁德时代"]
}
```

用户指定日期时，可补充 `queryDate`。

行情结果只用于说明价格、涨跌幅和数据时间，不得扩展为工具未返回的技术趋势。

---

### 5.3 资讯检索

从用户问题中提取：

* 公司名称；
* 行业或事件；
* 时间范围；
* 用户关注的影响。

示例：

```json
{
  "query": "宁德时代近期重要公司事件及行业政策影响",
  "maxSize": 5
}
```

## 6. 返回结果解析规则

财富 MCP Tools 通常返回统一外层结构：

```json
{
  "code": "...",
  "success": true,
  "message": "...",
  "class": "...",
  "data": "..."
}
```

处理规则：

1. 先检查 `success` 和 `code`。
2. `data` 为字符串时，应二次解析。
3. 检查返回股票是否与用户指定对象一致。
4. 只提取与用户问题相关的字段。
5. 不展示完整原始 JSON、内部 class 或 debug 信息。
6. 字段缺失时明确说明，不得自行补全。
7. 资讯应保留来源和发布时间。
8. 工具生成文本和结构化事实必须区分表达。

## 7. 工作流策略：五步轻量个股研究法

### Step 1：确认股票和分析目标

识别：

* 股票名称或代码；
* 所属市场；
* 用户关注重点；
* 时间范围；
* 是否需要行情或近期资讯。

如果对象不明确，应先确认股票，不得继续分析。

---

### Step 2：建立公司基础画像

调用 `queryStockKypInfo_7192`，提取稳定字段：

* 股票名称和代码；
* 交易所；
* 申万行业；
* 申万行业代码；
* 主营业务。

重点说明：

* 公司主要从事什么业务；
* 属于什么行业；
* 业务可能受到哪些产业因素影响。

工具未返回市场份额、业务收入占比或行业排名时，不得自行认定公司是行业龙头或市场第一。

---

### Step 3：整理行业和公司分析观点

提取工具返回的：

* PEST 分析；
* SWOT 分析；
* 波特五力分析；
* 行业亮点；
* 基本面总结。

这些内容属于工具生成的分析文本，并非结构化财务事实。

处理规则：

1. 提炼核心观点，不原样堆砌长文本。
2. 区分行业环境、公司优势、公司压力和潜在风险。
3. 使用“工具返回的分析认为”“当前生成式总结显示”等表达。
4. 不将生成式观点包装为已验证事实。
5. 缺少明确时间时，应提示内容可能存在时效性限制。

---

### Step 4：补充行情和近期事件

用户询问当前表现时，调用 `querySecuQuote_7681`，提取：

* 股票名称和代码；
* 当前价格或收盘价；
* 涨跌幅；
* 数据日期。

用户询问近期变化、涨跌背景或政策影响时，调用 `search_3347`，提取：

* 资讯标题；
* 内容摘要；
* 来源；
* 发布时间；
* 与公司或行业的可能关联。

不得将某条资讯直接认定为股价涨跌的唯一原因。

不得在没有技术指标时判断趋势反转、支撑位、压力位或买卖信号。

---

### Step 5：总结优势、压力与数据边界

最终结论包括：

#### 公司画像

* 主营业务；
* 所属行业；
* 基本业务特点。

#### 行业环境

* 政策、经济、行业和竞争因素；
* 工具返回的 PEST 或波特五力观点。

#### 相对优势

* 工具返回的业务特点；
* SWOT 中的优势与机会；
* 近期可能的积极事件。

#### 主要压力

* SWOT 中的劣势与威胁；
* 行业竞争；
* 政策、需求和成本变化；
* 近期事件带来的不确定性。

#### 行情和事件

* 当前或指定日期的行情；
* 近期重要资讯；
* 资讯可能产生的影响。

结论应使用条件化表达，不得输出确定性涨跌判断。

---

## 8. 数据能力边界

当前 `queryStockKypInfo_7192` 稳定返回：

* 交易所；
* 申万行业；
* 申万行业代码；
* 主营业务。

PEST、SWOT、波特五力和基本面总结属于生成式分析文本。

当前工具未返回：

* 营业收入和净利润；
* 现金流、资产负债和盈利能力；
* 毛利率、净利率和 ROE；
* PE、PB、PS 和估值分位；
* 行业估值及同行比较；
* 技术指标；
* 资金流向；
* 机构评级和目标价。

因此不得判断：

* 公司财务质量是否优秀；
* 当前估值是否高估或低估；
* 股票是否处于明确买点；
* 未来目标价或上涨空间。

## 9. 输出规范

### 推荐输出结构

```text
一、公司画像
- 主营业务：
- 所属行业：

二、行业与竞争环境
- 工具返回的行业观点：
- 主要机会与压力：

三、公司优势与风险
- 相对优势：
- 主要风险：

四、行情与近期事件
- 当前行情：
- 近期事件：

五、结论与数据边界
- 当前可以确认：
- 当前无法判断：
```

总体要求：

1. 结构化事实与生成式观点分开表达。
2. 涉及行情时标注数据日期。
3. 资讯应标注来源和发布时间。
4. 不编造财务、估值、技术面或资金面数据。
5. 不使用股价高低代替估值判断。
6. 不输出目标价、买卖建议或收益承诺。
7. 回答可根据用户关注重点缩短，不要求每次展示全部模块。

## 11. 错误与降级处理

### 股票对象未识别

1. 说明当前未识别该股票。
2. 提示用户提供更准确的名称或代码。
3. 不自行生成证券代码。

### 基本画像成功、生成文本缺失

可以基于交易所、行业和主营业务回答，并说明当前未返回完整行业分析。

### 行情查询失败

继续输出公司和行业画像，但不得补充价格或涨跌幅。

### 资讯查询失败

不影响基础分析，应说明当前未成功获取近期资讯。

### 用户询问财务或估值

明确说明：

> 当前工具未返回结构化财务或估值数据，因此无法完成可靠的财务质量或估值高低判断。

不得使用生成式基本面总结替代财务数据。

## 12. 示例流程

### 示例 1：个股综合分析

用户：

> 帮我分析一下宁德时代。

流程：

1. 调用 `queryStockKypInfo_7192`。
2. 提取主营业务、交易所和申万行业。
3. 整理 PEST、SWOT、波特五力和基本面总结。
4. 调用 `querySecuQuote_7681` 补充行情。
5. 必要时调用 `search_3347` 补充近期事件。
6. 输出公司画像、行业环境、优势、压力和数据边界。

---

### 示例 2：基本面问题

用户：

> 这家公司基本面怎么样？

流程：

1. 获取公司和行业画像。
2. 整理工具生成的基本面与 SWOT 观点。
3. 明确说明当前没有收入、利润和现金流等财务指标。
4. 只输出业务与行业层面的轻量判断。

---

### 示例 3：估值问题

用户：

> 这只股票估值贵不贵？

流程：

1. 判断问题需要 PE、PB、PS、历史分位或同行估值。
2. 当前工具未返回相关数据。
3. 明确说明无法判断估值高低。
4. 不使用股价或行业观点代替估值分析。

---

### 示例 4：近期涨跌原因

用户：

> 宁德时代最近为什么跌？

流程：

1. 调用 `querySecuQuote_7681` 获取行情事实。
2. 调用 `search_3347` 查询近期公司和行业资讯。
3. 总结可能相关的事件与行业因素。
4. 说明资讯与股价只能构成可能关联，不能证明唯一因果。
